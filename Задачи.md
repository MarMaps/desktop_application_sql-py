# Список задач (Project Tasks)

## Выполнено:
Реализована работа с конфигурационными файлами:

### 1. config_manager.py
- Библиотека `configparser` для создания ini-файлов
- Файлы хранятся в `~/.config/links_app/` (скрытый каталог)
- Для каждого пользователя свой файл: `username.ini`
- Сохраняются данные подключения к БД (хост, имя БД, порт, пользователь, пароль)
- Сохраняется тема приложения (light/dark)

### 2. theme_manager.py
- Две темы: светлая (light) и темная (dark)
- Переключение через кнопку "Сменить тему"
- Тема сохраняется в конфигурационном файле

### 3. Изменения в приложении:
- bd_vhod.py: добавлена опция сохранения настроек подключения
- main.py: добавлены кнопка смены темы и передача config_manager

### Каталоги:
- `get_program_dir()` - возвращает каталог, где находится программа
- `get_user_config_dir()` - возвращает каталог для конфигурационных файлов

Нужно реализовать работу с конфигурационными файлами. 
Например: пользователь авторизовался к БД -> необходимо сформировать конфигурационный файл, записать туда данные, которые вводил пользователь. Конфигурационные файлы должны храниться в скрытом каталоге. Для каждого пользователя свои конфигуроционные файлы.
Например, для пользователя student - все храниться в его домашнем каталоге,
для admin - все храниться в его домашнем каталоге.
То есть, в настройках должна храниться информацию о например: авторизации(данные БД, чтобы пользователь каждый раз не вводил их),

Например: /home/student/.config (здесь должен быть соответвующий каталог со всеми настройками программы)
